### CODE-012 · 模型上下文上限事实源 A+B 完成

#### 唯一解析与兼容

- 新增服务端上下文窗口 resolver，统一模型族与 unknown 128K 回退；前端不再维护第二套模型族表。`/v1/models` 只接受白名单 metadata 和 1,024～2,000,000 的整数，别名冲突及同 base URL 多 Key 候选取最小值；模型缓存继续读取 v1 字符串列表，live 成功后写 v2，损坏或刷新失败安全回退且不会提高能力上限。
- 上下文能力按可信 metadata → 统一模型族 → unknown 128K 解析；A+B 未加入专家覆盖或持久校准。旧客户端 `contextLimit` 只作为向下兼容 hint，不能伪造硬能力；旧 AgentRun 已有 `contextLimit` 原样恢复，新增字段保持可选，Child、Goal successor、queue/background 按既有边界继承或在创建时冻结。
- canonical Agent v1 `created` payload 以向后兼容可选字段登记 `contextWindowTokens`、`contextBudgetTokens`、`contextWindowSource`、`contextWindowHard`、`availableInputTokens`、`compressionTriggerTokens`、`budgetClamped`、`budgetAboveEstimate`，协议版本仍为 1，旧事件与旧 trace 无迁移。

#### 用户预算、持久化与展示

- 设置页模型区调整为“温度/最大输出”两列加“上下文预算”独占一行；预算单输入支持留空/`auto`、整数及 K/M 后缀，非法输入恢复上次有效值且不覆盖存储。Max Tokens 从 canonical 控件初始化并跨重开/刷新保持，不被预算修正静默改变；硬上限和 1,024～2M 范围会钳制，family/unknown 估算允许显式尝试突破并给出短提示。
- 新 AgentRun 冻结模型能力、用户预算和最终 `contextLimit`；输入预算扣除 Max Tokens 与 `max(4096, floor(contextLimit×5%))` 安全余量，压缩阈值取 `min(floor(contextLimit×90%), availableInputTokens)`。完成 Run 的安全 context resolution 原子写入既有 Session stats 可选字段，同 Run 重放幂等且旧 Run 不覆盖较新快照；旧 Session 缺字段继续安全回退而不被静默重写。
- 顶部环图外层只显示整数百分比，展开 Token 面板显示“百分比 · 最终冻结窗口”。自动压缩模型生成的 checkpoint 继续保存在 AgentRun 内部消息和 compaction 记录中，但其 Runtime 在 live、压缩中刷新和完成后恢复均不投影为普通 assistant；对话只保留“上下文已自动压缩”状态行和唯一最终回答，内部摘要不计消息数、不带复制/用量 footer、也不进入导出。
