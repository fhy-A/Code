- 修复同一模型轮含多个工具调用时，Run 取消后未开始或未闭合工具残留为“等待执行”的问题。取消提交现由服务端在同一临界区闭合工具事实：正在执行的命令沿用原有 `result.cancelled: true` 结果且只写入一次 `tool_completed`；尚未开始的工具写入带 `cancelledBeforeStart: true` 的耐久取消结果，不执行工具逻辑，也不产生 `tool_started / command_started`；全部工具闭合后才最后写入 Run `cancelled`。
