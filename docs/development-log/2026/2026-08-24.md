#### 完成内容

- 浏览器不再直连目标站、FaviconKit、Google 或 DuckDuckGo 图标地址，只向同源 `GET /api/favicon?scheme=...&host=...` 请求图标；失败继续显示既有主题化地球图标，外链 href、完整 URL tooltip、右键复制、图片/文件卡和 bundle/direct classic 入口保持不变。
- 服务端仅接受规范化 HTTP(S) scheme 与 host，拒绝任意 URL、路径、端口、userinfo、IP literal、localhost、单标签和 `.local`；候选顺序为经校验目标/父域的 `/favicon.ico` 与固定 allowlist provider，不抓取或解析目标 HTML，也不把早期“页面声明发现”方案写入实际实现。
- 每个目标和重定向都要求 DNS 返回集全部为公网地址，并把 TCP 连接固定到已验证地址；HTTPS 继续以原主机名完成 SNI/证书校验，拒绝私网、环回、链路本地、保留/组播、混合公网私网解析、peer 漂移、重定向循环、非默认端口及逐跳 HTTPS 降级。请求不携带 Cookie、Authorization 或 Referer。
- 出站请求采用总 deadline、单 socket timeout、并发上限、三次重定向、256 KiB、MIME 与 raster magic 双校验，拒绝 SVG/HTML；响应头及每次 body read 都按剩余总 deadline 收紧。合法 `Content-Length` 精确读满后立即完成并进入正缓存，提前 EOF/超额字节拒绝；无长度/chunked 响应仍逐次收紧，并在协议确认 closed 后正常完成。
- 解析结果使用 128 项有界内存 LRU、正缓存 6 小时、负缓存 5 分钟与同 host 请求合并；并发槽饱和属于临时容量拒绝，不写负缓存，非预期异常固定返回无内部细节的 `favicon unavailable`。未新增磁盘缓存、localStorage 第二缓存、依赖、凭据或持久化格式。
