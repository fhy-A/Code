# Code v0.6.13 Release Notes

日期：2026-09-17

<!-- code-release-notes:body:start -->
## 启动与更新稳定性

- 收敛应用启动序列：启动后置步骤抽为共享实现，由 `launcher`、`run_server`、`dev_server` 三个入口共用，消除打包版与开发版的启动序列分叉。
- 修复依赖探测子进程继承父进程 stdin 导致的启动停顿：探测此前会在特定环境下等待输入直到 8 秒超时，现已不再继承 stdin，并补上字面量 `None` 能力标识。

## 会话与侧栏

- 会话组默认收起为 5 条，其余折叠为「展开其余 x 个会话」（x = 总数 − 5），补齐中英词条并修正旧守卫反转后的行为。
- 新建会话时不再残留上一次的欢迎页用量显示。
- 开发实例的初始标签标题统一为 `Code Dev`。

## 模型能力与推理档位

- 按 DeepSeek 官方文档完成带日期的模型能力识别与档位映射审计：采用官方现行名 `deepseek-flash`（上下文 1M / 输出 384K，旧名保留为别名），并同步推理档位映射。
- 修正能力探测中把字面量 `None` 当作能力标识的问题，避免错误声明能力。

## Goal 与输出预算

- 完成同 Session Goal 收尾闭环（含归档验收），并修复工具终态与 Goal 验收闭环的衔接。
- 统一 Goal 来源引用契约：来源引用支持可选的 `version` / `contentHash`，字段报错更明确。
- 新增输出预算与截断停止：单次输出超出预算时按规则截断并明确停止，前端同步展示（含归档标题布局修正）。

## 上下文与记忆

- 上下文「高级设置」简化：默认折叠，单次输出统一留空自动，保留原有 auto/数字保存与隐藏上下文行为。
- 修复记忆事务与请求上下文一致性（版本绑定删除授权、请求时刷新），并更新默认宿主架构记忆为面向用户视角的使用环境参考。

## 项目会话归档

- 新增项目会话批量归档，并完成归档分组永久删除与整体收口。
- 新增跨项目「删除全部已归档会话」，优化归档确认与结果反馈展示（分组计数、筛选内边距与箭头留白修正）。
- 修复压缩前归档写入：归档备份文件不再被误判为会话元数据而写入失败；归档 JSON 与 JSONL 备份内容保持一致。

## 预览工作区与本轮改动审查（CODE-042 已验收范围）

- 完成会话隔离的多标签预览与切换体验。
- 完成本轮改动文件卡片与受限删除差异审查：逐操作只读差异、仅本地删除正文，改动文件卡片复用文件树右键菜单。
- 预览标签支持拖动换位与跟手动画；空白页提供文件树预览；按图片边界保留相邻工具调用顺序。
- 未纳入本版本的后续范围：切换会话复用已验证列表缓存、刷新后自动加载当前可见改动卡片，以及运行中审查入口，均属后续版本范围。


## 已知限制

- 归档沿用白名单式删除路径，不做任意外部写入；旧记录、二进制与超限项不会回填为完整结果。
- 预览工作区的运行中审查与缓存优化不在本版本承诺范围内。
