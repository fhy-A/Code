# Code v0.6.10 Release Notes

日期：2026-09-11

<!-- code-release-notes:body:start -->
## 更新重点

- 统一模型选择与推理强度入口，按已适配型号的静态能力提供默认／低／中／高档位；未选择模型时明确提示先选择模型，输出预算不足时禁用相应档位。
- 新增独立的表达详略（默认／简洁／详细）和交流语气（默认／专业／轻松）设置。任务提交时固定偏好，排队、重试和恢复沿用原快照；默认组合保持原行为，高级温度设置继续保留。
- 改善文件工具的失败反馈、大文本后段读取和目录／搜索结果完整性展示，减少失败调用生成虚假编辑建议的情况。
- 优化工具轨迹、图片查看、行动状态、时间线跳转、运行中追加消息和更新重启体验。

## 模型、推理与回复风格

- 完善 OpenAI、DeepSeek、Claude 的档位编译与工具回传适配。GPT／DeepSeek 使用 Chat，Claude 使用原生 Messages；必需的推理内容、签名和工具参数完整保存并校验后才执行工具，缺失字段、错误结束或保存失败不会触发盲重试。
- 旧的、不兼容的助手和工具历史通过带来源的公开文本衔接；更换模型、连接或历史前缀后开启新的协议段，不跨边界复用旧签名。已完成工具账本在恢复中保留。
- 详略与语气属于柔性偏好，用户明确要求优先。三款模型的本地实测共 42 个案例、73 次请求，显示详略的方向性差异；语气差异较弱，部分扩展内容不够严谨，长回答仍可能触及原输出预算而截断，不能保证每次更短、更完整或更准确。工具组合尚有未测项。
- 能力声明、适配器测试和真实连接验证分别处理。静态档位可选不代表所有模型、网关或渠道已通过线上验证；本轮没有完成 OpenAI／Claude 的真实模型全面验收。

## 文件操作与运行展示

- 工具调用失败或参数不完整时，不再生成缺少有效路径／内容的虚假编辑建议；对输出预算造成的参数截断提供更明确反馈。失败原因仍可能来自模型输出、路径、权限或环境，不承诺消除所有文件操作失败。
- 修复大文本请求后段行时受前部截断影响的问题，并限制读取窗口缓存；目录与搜索结果增加有界完整性摘要，区分完整、部分与未知，未知文件大小不再当作零。每轮请求补充当前工作区信息，命令对象输出先格式化再按原退出语义返回。
- 工具名称更具体；成功读取的图片可独立查看，缺失或不支持的预览明确回退。单项与批量授权区别展示，工具组和详情维持独立折叠及滚动位置，状态切换保持共同几何。
- 新增仅供展示的可选行动状态，随当前工具阶段更新，恢复、切换和失去前台归属时清空；显示元数据不进入实际执行参数或授权身份。修复时间线跳转被自动跟随覆盖的问题。
- 运行中追加的消息立即进入原会话展示；失败保留内容并提供显式重试，沿用稳定请求标识和原队列参数，避免重复提交。
- 外链图标改进浏览器加载、缓存及流式内容中的即时更新，移除无效来源。加载失败稳定显示地球占位，仍受网络、站点响应和浏览器策略影响，不保证任意网站都能取得图标。

## 更新、兼容与验证边界

- “更新并重启”先停止当前工作并确认保存，再下载、校验和重启；未知结果提供重新检查与手动入口。保留旧 EXE，不自动降级。实际冻结 EXE 的真实下载／安装升级尚未完成验证。
- 新读取器兼容已有 AgentRun v1–v7 和旧推理快照；新原生回传使用 `reasoningSnapshot` v3 与 `protocolReplay` v1，旧二进制的 v2 读取器会拒绝 v3。回退前应先处理新版活动、排队及需恢复的任务，保留数据备份和原始记录，不通过删除或降写字段强行兼容。
- 回复风格新快照使用 v2，已经创建的 v1 快照保留原措辞；未知或损坏快照明确报错并保留原记录，不悄悄套用当前设置。文件读取等既有 JSONL 无需迁移。行动状态回退先停用新字段声明与展示、保留解析兼容；退回旧二进制前排空新协议在途任务。
- 发布工具支持精确复用候选、受控重新准备及中断审计；本版正式门禁使用完整检查，检查集合、顺序与断言覆盖与原 1500 秒时代完全相同。本机吞吐相对 2026-09-08 基线下降约 2.6 倍（同代码同命令在 09-08 当天内部即波动 26%：994.79 秒与 1256.61 秒），实测完整套件约 2609 秒，故全量 pytest 上限设为 3600 秒，仍不沿用上一版的一次性差量验收例外。发布前已对齐过期恢复夹具、可选 schema 与布局保护，并补充真实 owner 负向检查。
- 既有功能验证包含确定性、隔离适配器与页面专项；H4 不属于正式 release profile。外链图标旧会话创建链的四项 H4 曾在到达图标断言前失败，专项页面通过不等于该完整链已通过；模型静态适配、图标回退和真实 EXE 升级的上述限制继续保留。
