# Code v0.5.31 Release Notes

日期：2026-08-01

<!-- code-release-notes:body:start -->
## 主要更新

- 完成开发实例与正式版本隔离：正式 EXE 固定使用 `127.0.0.1:3010` 和 `%USERPROFILE%\.code\`，开发实例默认使用 `127.0.0.1:3011` 和仓库 `data/`；两套进程、托盘标识、重启入口和数据目录可以并行运行，避免源码调试影响已安装正式版。
- 优化 Agent 执行反馈：首次发送先同步渲染用户消息和运行状态，降低长会话下的短暂卡顿；执行轨迹按阶段组织思考摘要和工具记录，完成后收进“已处理 + 总耗时”，工具组使用轻量折叠标题与统述表达。
- 按职责推进 `app.js` 模块化：完成应用状态、会话持久化与 CRUD、前台导航、启动恢复、分支，以及 Agent 模型流、请求装配、工具、权限、问卷、子 Agent 和上下文压缩纯边界；保留网络、DOM、持久化和运行时副作用在现有编排层，不以行数目标强行迁移高耦合代码。
- 新增 `/compact` 手动压缩命令并将内置命令与 Skills 分组展示；手动压缩默认保留最近 3 个完整用户轮次，工具调用与结果不会在保留边界处拆开。
- 新增 AgentRun 自动上下文压缩：达到当前上下文上限估算的 90% 时生成检查点摘要，并在同一任务中继续；上游明确返回上下文超限时最多执行一次响应式压缩与重试。压缩事件按实际时序进入执行轨迹，自动流程不弹确认框。

## 兼容性与边界

- 现有会话 JSONL、AgentRun 持久记录、工具协议和手动压缩 API 保持向后兼容，旧数据不需要迁移。
- 3010 与 3011 是不同的浏览器来源，workbar 登录态和浏览器本地保存的 Key 分别维护；这属于隔离设计，不会自动同步。
- 上下文上限目前仍以模型族规则作为默认事实源；自定义模型或渠道的真实上限覆盖方案已列入后续优化，本版本保留上下文错误后的单次恢复兜底。
- 第五阶段 5G `agent-loop.js` 审计和阶段 6 esbuild 尚未纳入本版本。

## 本次更新后的首次人工验收

1. 从现有正式版执行更新或下载 `Code-v0.5.31.exe`，确认安装完成后应用版本显示为 `0.5.31`。
2. 确认正式版打开 `http://127.0.0.1:3010/`，托盘名称为 `Code`，原有正式会话和配置仍可读取。
3. 保持或重新启动开发版，确认其仍打开 `http://127.0.0.1:3011/`，托盘名称为 `Code Dev`，且使用仓库下的开发数据。
4. 同时运行两套实例，分别发送一条普通消息并重启，确认端口、会话、登录态和重启入口没有串用。
