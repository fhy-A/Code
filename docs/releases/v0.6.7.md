# Code v0.6.7 Release Notes

日期：2026-09-01

<!-- code-release-notes:body:start -->
## 更新重点

- Code Web 完成新一轮视觉系统收敛：侧栏、顶部工具栏、文件区、欢迎页、输入区、普通消息、搜索 / 归档、设置与导入会话使用一致的字号、间距、图标、边界和状态层级，保持 PC Web 开发工具的紧凑密度。
- 更新下载改为服务端权威、同版本 single-flight 任务；设置页重开和服务恢复可接管同一下载，支持严格 Range 续传、完整性校验和脱敏失败状态，重复点击不再产生第二个写入者。
- 普通主 Agent 与持久 Child Agent 统一为不因固定模型轮次停止；Child 仅继承父 Run 的兼容 `maxRounds` 字段，旧 `5 / 8` 记录继续可读和恢复，不再触发硬停止。
- Skill Runtime Binding v1 为 AgentRun 冻结实际可用的 Skill capability 与受管 Python / Node 运行时，在授权前、执行前及恢复时重验 lock、receipt 和受控路径，不向 Child Agent 扩大权限或工具集。
- 会话停止与归档形成稳定闭环：无活动工作的 Goal 不再误阻断归档，真正运行中的前台、后台或 Child Run 会先经用户确认停止，再以会话 fence 和有界取消完成原事务归档。
- 连接名称继续只是显示标签：空名称在持久数据和路由目录中保持为空，“未命名连接”仅由前端按当前语言投影，不改变 connectionId、routeRef 或同名模型精确选择。

## Code Web 界面与交互

- 第一阶段高频外壳建立局部可复用的 typography、spacing、radius、control、icon 和 elevation 尺度；左侧栏与右侧预览同时展开时，预览宽度按实际 workbench 夹紧，为中间会话区保留至少 `520px`。欢迎标语收敛为“把想法变成结果”，输入提示为“输入想法，或使用/命令”。
- 会话侧栏使用单一状态位表达等待、运行、失败、未读与空闲时间；长标题按可用宽度渐隐和单次滚动。项目置顶、新建、右键编辑和文件区高度夹紧共用清晰的焦点、回焦和深浅主题反馈。
- 普通用户 / 助手消息、长消息底部操作行、Markdown 标题、引用、admonition、表格、代码、文件卡和图片预览完成可读性与可访问性审计；只有真正横向溢出的表格获得键盘滚动区语义，文件 / 图片操作使用原生可操作控件。
- Diff 编辑建议、授权队列和 `request_user_input` 问卷收敛为扁平层级；展开 / 折叠、批量授权、调过、接受与拒绝语义不变，长回答使用可访问的局部展开。
- 会话搜索、归档列表、模型 / 生图模型、记忆、System Prompt、编辑器、Skills、workbar 账号、更新页、顶部会话工具栏和导入会话窗口统一为紧凑、低噪声的外壳；现有 API、导入、路由、凭据、存储和安装语义保持。
- 全局文本输入、搜索、textarea 和原生 select 的焦点反馈统一为单层 `1px` 强调边框；搜索 / 项目编辑由外壳唯一描边，System Prompt 仅强化底线，composer 只保留中性表面阴影。按钮、checkbox / radio、drag / disabled 和错误 / 警告状态不变。

## 下载、会话恢复与受管运行时

- 服务端以官方 GitHub Release 描述中的版本、固定资产名、URL、size 和 SHA-256 为权威；旧客户端提供的 URL 只在与权威描述完全一致时兼容。续传 sidecar 版本化、原子且不含秘密；损坏、越界或冲突状态 fail-closed。
- 安装前依次校验受管目录、非 reparse 路径、单链接普通文件、精确 size / SHA-256 和 PE 版本 / 文件名；restart 只接受已验证 completed jobId，重复 restart 不会启动第二个安装进程。
- 会话归档前会区分无活动工作的 Goal 与真正运行中的 AgentRun；取消传播、恢复后 sidecar 和归档事务继续遵守原会话 / 路由 / 凭据边界，失败会区分“未能停止”与“已停止但归档失败”。
- 受管 Skill 运行时只为当前 AgentRun 允许的 capability 注入可信 Python / Node 环境，安装依赖后必须重新检查再绑定；stale、冲突、越界 / reparse、receipt 不一致在 worker 启动前拒绝。
- 新 Child 运行保留父子 Session、route、model、context、权限、取消、最多三个并发委派、工具去重和用量合并边界；旧 `run_subagent / SUBAGENT_MAX_ROUNDS=5` 不可达同步死代码已移除，旧记录无需迁移。

## 安全、兼容与验证边界

- 更新任务公开状态只包含稳定 errorCode、retryable、阶段和脱敏文案所需事实，不返回本地绝对路径、URL 查询、上游响应正文或原始 OSError。
- 受管运行时、Child Agent 和界面改动都沿用既有 permission / tool / workspace / route / context 与恢复边界；旧 AgentRun 的兼容字段、旧会话、旧下载记录和合法历史宽度继续可读，不执行批量迁移。
- 本版本的视觉变更以 PC Web 桌面工作区为验收范围，不改信息架构、业务文案含义、输入 / 发送 / 附件 / 模型 / 权限语义、会话存储或公开 API。
