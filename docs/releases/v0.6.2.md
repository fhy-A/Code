# Code v0.6.2 Release Notes

日期：2026-08-14

<!-- code-release-notes:body:start -->
## 更新重点

- 完成长文本展示、文件树静默刷新和新消息阅读锚点三项会话体验改进，减少长内容占屏、手动刷新文件树以及流式回答期间的视口跳动。
- 稳定工具执行轨迹与编辑建议 Diff：普通状态更新复用既有节点和展开选择，编辑 Diff 默认收起且可从授权面板准确查看；重复同源提案也能保持独立卡片、授权和结果投影。
- 新增 `python verify.py quick|ui|runtime|release` 统一只读验证入口，并让 `release.py` 复用同一 release 门禁定义；正式发布的检查顺序、超时、失败传播和 `--dry-run` / `--skip-tests` 外部语义保持不变。

## 长文本与文件树

- 输入框草稿只有在真实溢出时才显示“展开输入”，展开后继续允许内部滚动；收起或展开不会改变全文、光标、选区、焦点及最终发送内容。
- 已发送的用户长文本在桌面和移动尺寸下按真实溢出默认收起，可展开完整 Markdown；短文本、图片和附件保持原样。发送、steer、queue、`/parallel`、模型上下文、复制和 Session JSONL 始终使用完整原文。
- 当前页面内的长文本展开选择在普通重绘中保持，刷新或切换会话恢复默认收起；布局变化继续遵守既有滚动所有权。
- 每个真实用户轮次进入成功、失败或取消终态后，当前可见文件树会静默刷新。queue/steer 只在主轮真正结束时触发，detached `/parallel` 按自身终态触发，授权、问卷和仅入队等中间态不会提前刷新。
- 静默刷新保留当前项目、目录、搜索、预览选中和滚动位置，并通过合并、同轮去重、latest-wins、过期响应丢弃和失败保留旧树避免闪动或旧响应回写。

## 阅读锚点与流式滚动

- 新的真实前台轮次会建立仅存在于当前页面的阅读锚点，为首段回答保留稳定空间；回答、工具、图片增长及用户向上滚动只会单调消耗临时空白，同一轮不会因重绘、缩放或输入框高度变化重新增加。
- 用户首次真实向下滚动或点击“一键到底”会一次释放剩余空白并转向真实消息底部，避免先滚入空白后再次跳转。
- 按钮显隐只使用排除临时空白和布局补偿后的真实内容距离，继续保持 `160px` 显示阈值；滚动所有权独立保持 `2px` 到底容差和防回弹语义。
- queue 仅在真正开始前台执行时创建锚点；已接受 steer 替换当前锚点，`409` 入队等待后续真实执行，恢复中的 steer 与 detached `/parallel` 不污染前台锚点。刷新或切换会话清除临时状态并定位真实最新消息。

## 工具轨迹与编辑 Diff

- 执行轨迹、工具组和工具项按稳定身份原位更新标题、状态、参数和结果，避免普通工具事件导致整组销毁重建。活动任务保留用户展开或收起选择，真实成功、失败或取消终态只折叠一次，完整刷新仍默认折叠。
- 折叠标题的鼠标操作不再产生跨工具正文、Diff 或阶段说明的异常文本选择，也不会显示浏览器白色或主题绿色指针焦点轮廓；正文和 Diff 仍可选择复制，键盘 `focus-visible`、Enter/Space 和 `aria-expanded` 保持可用。
- 编辑建议卡片持续显示文件路径、增删统计、状态和授权操作，Diff 正文首次展示及刷新后默认收起；多个编辑建议在当前页面内独立展开，普通流式、授权状态和完成投影更新不会反复收起。
- 授权面板“查看”会展开、定位并短暂低强调高亮目标卡片，不改变勾选或批准/拒绝语义。重复同源提案以前端实例键隔离，第一次拒绝与后续再次授权、批准和应用各自保持正确卡片和唯一副作用。

## 验证与开发流程

- 长文本、文件树、阅读锚点、工具组和编辑 Diff 阶段分别通过统一 UI、相关前端构建/freshness、语法、差异及必要 H4 门禁，并完成 Code Dev 与 direct classic 人工验收；最新编辑授权阶段为统一 UI `224 passed`、双入口编辑授权 H4 `6 passed`。
- 统一验证入口提供稳定的 profile、执行项、跳过项、首个失败点和最终结果摘要。H4 只属于 `runtime` profile，不进入 release profile；`release.py` 不重复执行共享门禁。
- 协作规则已按 QUICK / STANDARD / STRICT 风险分级，并为正式发布固定候选基线和 next-cycle 队列边界；唯一 TODO 已整理为 workbar / Code 双域、稳定 ID 和单一执行状态。
- Goal 长任务指导补充了用户实机观察到的三态进度展示参考，但本版本仍未实现 `/goal`、Goal 工具、自动续跑或 Goal UI。

## 兼容与边界

- 本版本没有修改服务端 API、Session JSONL、AgentRun、工具或授权协议，也没有新增持久化格式或数据迁移；旧会话无需迁移。
- 文件树继续复用既有 `/api/files`，编辑建议继续沿用服务端 proposal、authorization 与 apply 幂等语义；所有新状态均为前端投影或当前页面内瞬态状态。
- 默认 bundle 与 direct classic 继续共享相同前端行为。未完成的 Goal、工具组标题流光、系统提示词工程化等事项不属于本版本。
