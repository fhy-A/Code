# Code v0.5.30 Release Notes

Date: 2026-07-28

## Highlights

- Added a 120-second hard deadline for the first meaningful model response. SSE keepalives, empty frames, role-only events, and usage-only events no longer keep a stalled request alive indefinitely.
- Hardened Agent recovery for empty replies, reasoning-only turns, and promise-only responses: one automatic continuation is allowed, then the run stops with a clear recoverable error if no executable action or complete answer appears.
- Added strict tool argument validation and a narrow Claude compatibility alias for `read_file.file_path` to `path` at the Agent boundary, while keeping the direct tool API strict.
- Added repeated-failure protection for identical tool calls, with normalized fingerprints, structured failure outcomes, retry limits, and durable recovery state.
- Reworked tool-round presentation into compact structured process cards, separated initial model waiting from post-tool continuation waiting, and kept the displayed timer anchored to total task duration.
- Classified upstream content-policy termination separately from empty replies and removed duplicate rendering of the same structured Agent error.

## Compatibility

- Existing sessions and durable Agent records remain compatible; older tool records infer success or failure from their stored result.
- Python and Node Skill dependencies remain confined to the Code-managed isolated runtime. System dependencies remain hint-only.

## Verification

- Full automated test suite is executed by `release.py` before packaging.
- JavaScript syntax checks, Python compilation checks, `git diff --check`, EXE metadata validation, and SHA-256 generation are included in the release pipeline.

## Packaging

- `VERSION`, `file_version_info.txt`, `README.md`, and the PyInstaller spec are synchronized.
