# Code v0.6.11 Release Notes

日期：2026-09-11

<!-- code-release-notes:body:start -->
## 更新重启修复

- 修复应用内“更新并重启”在安装阶段中断、新版本不启动的问题：更新完成后新版本会正常启动；如果启动仍然失败，界面会给出可见的错误提示，并把原因写入可复核的日志，不再出现“点完之后毫无反应”。
- 更新过程中不再删除或覆盖安装目录中的既有版本文件，也不会强制结束正在运行的旧版本。

## 已知限制

- 从 v0.6.8 / v0.6.9 升级到本版的用户：这次更新由旧版本自带的更新器执行，无法自愈；下载与落盘正常，但更新完成后需要手动双击一次安装目录（用户主目录下的 .code）中已下载的 Code-v0.6.11.exe 才能启动新版，之后快捷方式会自动指向新版本。
- 真实冻结 EXE 的应用内升级验收尚待用户在本机完成，本版不宣称该链路已在真实 EXE 上通过。
