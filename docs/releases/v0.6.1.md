# Code v0.6.1 Release Notes

日期：2026-08-12

<!-- code-release-notes:body:start -->
## 更新重点

- 优化消息输入区与页面背景的视觉层级：输入区表面改为随当前主题相对混色，浅色、深色及非默认主题下均能保持清楚但克制的区分，并统一覆盖默认、hover、focus、防御性 disabled、placeholder、caret、附件缩略区和多行输入的连续表面。
- 增加历史消息“一键到底”入口和集中滚动接管。用户明显离开底部时可快速返回最新消息；空闲状态显示向下箭头，当前会话前台任务运行中显示水平等距的三点进度动效，按钮在明暗主题、移动尺寸和动态输入区高度下保持稳定。

## 输入区层级与文件拖放

- composer 默认表面基于当前主题背景向文字色混合约 6%，hover 约 8%，防御性 disabled 约 3%；focus 延续 accent 边框与低透明光晕，placeholder 明确使用 muted 色且保持完整不透明度，caret 使用 accent 色，没有为单一主题硬编码固定灰值。
- 普通输入区、空会话输入区、附件缩略区、2～5 行多行输入及底部控制区共享连续表面；附件拖入时使用轻量 accent tint，不改变附件接收、重复 drop 防护或发送语义。
- 文件拖放改由 form 级深度计数统一处理。只有真实文件拖放才激活反馈，指针经过输入区子节点时不会闪烁，离开或 drop 后会稳定清理状态。

## 历史消息一键到底

- `#messages` 的跟随、用户滚动接管、历史位置保持和按钮显隐由同一控制器管理。离底达到 160px 时显示入口；回到真实底部 2px 几何容差内、点击按钮或显式切换/重新载入会话时恢复跟随。
- 用户任何有效的向上 wheel 或 touch 意图都会在真实 scroll 前取消待执行的跟随帧。用户离底不足 160px 时按钮可以不显示，但视口位置仍会保持，不会被后续流式内容、图片、工具布局或 ResizeObserver 更新抢回底部。
- 短会话仅轻微溢出时，`awaitingUserScroll` 会在首次真实 scroll 到达前保护浏览器产生的小幅位移，防止内容或视口回调以旧底部位置覆盖第一次滚动。无可滚内容、横向手势、缩放手势、轻点、向下滚动、会话重置和点击到底均安全收口。
- 运行中的三点使用水平等距、错峰明暗/位移动效，`prefers-reduced-motion` 下保持静态；空闲箭头与运行状态共用相同的 40px 几何、位置和点击行为。授权面板显示时入口会暂时隐藏，关闭后按实际距离恢复。
- 页面刷新、重新打开或切换会话仍定位最新消息，不持久化历史滚动位置；问卷、附件、多行输入、移动尺寸和动态安全区沿用同一避让规则。

## 验证结果

- 输入区阶段自动门禁通过：Node 语法检查、前端模块与 P2 定向回归 `235 passed, 4 subtests passed`、前端 bundle/classic 构建与 freshness 检查及差异检查均通过；用户完成浅深主题、附件拖放和既有发送行为的人工验收并确认 PASS。
- 一键到底阶段自动门禁通过：控制器定向 `3 passed`，前端模块与 P0 稳定性回归 `211 passed`，bundle/classic 定向 `3 passed`，前端构建门禁通过；完整 pytest 为 `1138 passed, 751 subtests passed`，仅保留既有 3 条损坏 TIFF EXIF 负测警告。用户完成长流式、运行/空闲图标、主题、首次滚动和短溢出复验并确认 PASS。
- 默认 bundle 与 direct classic 使用同一输入区主题、拖放和滚动控制行为。

## 后续开发指导与未实现事项

- 新增《Code Goal 复杂长任务规划、执行与验收开发指导》，固化三态顶层计划、普通消息驱动控制、跨 AgentRun 安全续跑、证据验收、恢复与幂等及权限边界，作为后续开发规范。
- 本版本没有实现 `/goal`、Goal 工具、自动续跑、持久化 reducer 或 Goal UI；指导文档落盘不代表这些能力已经可用。
- “用户长文本省略/收起展示”仅登记为后续 TODO。本版本没有实现输入框草稿或已发送用户消息的长文本省略、展开和收起行为。

## 兼容与边界

- 本版本没有改变 Session JSONL、服务端 API、工具协议或持久化格式，旧会话无需迁移。
- bundle 与 classic fallback 继续共享既有会话和运行时边界；输入区和滚动改动仅影响前端展示与交互，不扩大授权、安全或外部副作用权限。
- 相邻的“新消息发送后的阅读锚点与流式滚动”仍是独立未完成事项，不属于本版本。
