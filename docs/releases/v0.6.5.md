# Code v0.6.5 Release Notes

日期：2026-08-24

<!-- code-release-notes:body:start -->
## 更新重点

- 系统性提升最终回答的富文本可读性与文件交互：任务清单、嵌套列表、对齐表格、提示框、代码块、路径引用和图片预览在桌面与窄屏下保持清晰，并继续复用消息原文与既有复制语义。
- 历史会话改为在置顶规则之后按真实最后对话时间稳定排序，新增固定状态槽显示运行、未读、等待回答/确认和空闲相对时间；Goal 面板在会话切换期间按目标身份隔离，不再短暂投影上一会话内容。
- 大型文本继续在右侧使用服务端前 1 MiB 的截断预览，Windows 文件“在文件夹中显示”可精确选择目标并安全恢复对应 Explorer 窗口前台；显式默认程序打开仍保留。
- 修复 Gemini-GCP Goal 工具 Schema 兼容，并将外链网站图标迁移到受控同源代理，浏览器不再直接连接目标站或第三方 favicon 服务。

## 最终回答、链接与图片交互

- Markdown 投影补齐五类 Admonition、宽表容器、稳定标题锚点、代码语言标签、路径行号引用和嵌入图片占位；路径和链接继续支持完整 tooltip、精确打开、行号定位及按类型收敛的右键菜单。
- GFM 任务项使用只读 checkbox 保留完成/未完成语义，点击不会改写消息；嵌套有序/无序列表改善层级与长文本换行，表格保留左/中/右对齐元数据，宽表只在自身容器内横向滚动。
- 普通本地文件链接改为轻量的单色图标与文件名，不再使用大块卡片外框；图片路径继续保留缩略图卡。路径识别、二进制路由、越界降级、复制和右键行为不变。
- HTTP(S) 裸链接遇到全角括号、顿号、句号等 Unicode 标点时可正确结束，连续网址不再被合并；标准 Markdown 链接、代码、查询参数、fragment、百分号编码及 `/中文`、`/한글` 等合法 Unicode 路径保持原行为。
- 输入框多图大图查看新增左右按钮、键盘方向键、当前索引和首尾禁用，并与附件删除后的实际顺序同步；单图、遮罩与 Esc 关闭继续兼容。

## 安全外链网站图标

- 页面只请求同源 `/api/favicon`，失败时使用主题化地球图标；外链 href、完整 URL tooltip、右键复制以及 bundle/direct classic 的交互保持一致。
- 服务端仅接受规范化 HTTP(S) host，只尝试经校验目标/父域的 `/favicon.ico` 与固定 provider 候选，不解析目标 HTML，不携带 Cookie、Authorization 或 Referer。
- DNS、每次重定向和实际连接地址均须为公网且保持一致，拒绝私网、环回、链路本地、混合解析、非默认端口、循环跳转与 HTTPS 降级；响应同时受总时限、并发、大小、MIME 和图片 magic 限制，SVG/HTML 不会作为图标返回。
- 图标使用有界内存 LRU、正负 TTL 和同 host 请求合并；并发饱和与非预期异常安全失败，不写入磁盘缓存或新的业务持久化数据。

## 会话排序、状态与 Goal 隔离

- 会话索引增加可选 `lastMessageTime`：真实用户/助手消息写入时同步，标题、项目、来源、置顶等纯 metadata 操作不会冒充对话活跃时间。旧索引只在字段缺失时锁内惰性回填，已有值不覆盖，损坏值安全回退。
- 旧的无时区时间在 API 边界按服务端本地时区规范化为 UTC；前端只解析明确时区值。续聊成功后使用服务端回包的权威时间立即重排，刷新、导入、分支和稳定同时间排序继续兼容。
- 会话标题右侧状态槽按“非当前会话等待回答 → 等待确认 → 运行 → 未读 → 空闲时间”投影已有事实；当前会话的问卷和授权仍由原面板唯一提示。分钟更新只原地修改空闲文案，不重排、不联网、不写存储。
- 运行环使用 1.4 秒动画并在同状态流式更新间保持 DOM 身份，避免重复回到起始角度；结束后仍正常进入未读或空闲状态，`prefers-reduced-motion` 下保持静态。
- 已接受的异会话切换会先隐藏旧 Goal 面板，只有目标 Session/Goal 身份匹配的响应才能显示；迟到响应被丢弃，加载失败恢复原会话，同会话点击和被既有防抖拒绝的点击不会误清空。

## 文件预览与 Windows Explorer

- 文件树和最终回答中的大型文本统一继续走内部 `loadFile`，只显示服务端最多前 1 MiB 及既有截断标记；字符数或行数门槛只关闭高成本语法高亮，不再隐式启动系统程序。
- 图片、PDF、二进制、路径越界、行号跳转和右键菜单保持原路由；“用默认程序打开”仍是文本文件显式启动外部程序的唯一入口。
- Windows 文件通过 Shell 原生能力打开父目录并选择精确目标，目录则打开精确位置；中文、韩文、空格和长路径的 Explorer 枚举固定使用 UTF-8，不依赖系统代码页。
- 仅当 Explorer 窗口的文件系统路径与目标精确匹配时才恢复和激活；普通前台请求被系统拒绝后，只对同一 HWND 做一次必撤销的临时 topmost 降级。歧义、超时或目标不存在时返回可理解的降级结果，不激活近似窗口。

## Provider 兼容与维护边界

- `goal_revise_plan` 工具 Schema 移除 Google `functionDeclarations` 不接受的同层 `anyOf`，改用普通对象的 `minProperties: 1`；Goal v2 协议层仍独立要求 objective 和/或 steps，没有放宽真实计划修订语义。
- Goal / DSH / pi 研究与设计文档已按历史日期归档，并明确版本、资料来源和有限验证范围；历史快照不替代当前代码、测试、TODO 与开发日志事实源。
- 清理 `Code-v0.5.28.spec` 至 `Code-v0.5.34.spec` 七个旧构建快照，保留 `Code-v0.6.1.spec` 至 `Code-v0.6.4.spec` 作为现行发布历史和模板来源。
- `data/goal-workflows/`、`data/goals-v2/`、`data/goals/` 仅作为本地运行时 sidecar 被精确忽略，实体数据未删除；`data/memory`、`data/skills` 与 `data/project-summary.md` 继续受版本控制。

## 兼容说明

- `lastMessageTime` 是可选加法字段，旧 Session、消息 JSONL、`updatedAt` 语义和历史会话无需破坏性迁移；旧版本可忽略该字段。
- 本版本没有新增可编辑任务清单、表格排序、HTML favicon discovery、磁盘图标缓存或新的 Session/AgentRun/Goal 协议版本。
- Windows 前台激活仍受操作系统策略约束；无法唯一定位或无法取得前台时会明确降级，不使用标题猜测、键盘模拟、永久置顶或常驻 helper。
