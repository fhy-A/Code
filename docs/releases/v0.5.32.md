# Code v0.5.32 Release Notes

日期：2026-08-01

<!-- code-release-notes:body:start -->
## 更新重点

- 前端默认入口切换为经过固定顺序构建的 esbuild bundle，开发版会在启动和页面刷新时检查产物新鲜度，源码变化后自动重建。
- bundle 加载或同步初始化失败时自动进入经典脚本回退页；经典页面和全部原始脚本继续保留，便于首个 bundle 正式版本稳定观察与回退。
- 正式 EXE 和发布流程加入前端强制构建、源码指纹、产物哈希及语法门禁，过期或损坏的 bundle 无法进入打包、提交和发布阶段。

## 体验与稳定性

- 修复 Code Dev 刷新页面时 Node 检查进程短暂闪现终端窗口的问题。
- 问卷工具执行轨迹改用“询问用户 / 询问了用户”等本地化统述，不再重复展示原始 `request_user_input` 过渡行；旧会话无需迁移。
- 完成 Agent 主循环状态所有权护栏与 app.js 第五阶段职责收口，保留高耦合入口编排层，避免为了减少行数引入不稳定的薄模块。

## 兼容与验证

- 会话 JSONL、工具协议、API、权限和配置格式保持兼容；打包后的 EXE 运行时不依赖 Node。
- 自动回归 899 项及 236 个子测试通过；本地 EXE 归档确认包含默认 bundle、经典回退页和原始脚本，不包含 source map、metafile 或构建状态文件。
