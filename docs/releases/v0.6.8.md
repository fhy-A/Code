# Code v0.6.8 Release Notes

日期：2026-09-04

<!-- code-release-notes:body:start -->
## 更新重点

- Skill 运行环境补齐可迁移的自有资源与依赖闭环：XLSX 公式重算、PPTX 校验与渲染由 Code 随包提供并经身份、路径和哈希校验后绑定；Git Bash、LibreOffice 等依赖可在安装后即时重检，无需重启 Code。
- 自动模式的工作区范围与风险提示更加准确：工作区仍是默认操作范围，用户明确提供的外部路径可按任务需要访问；未经明确要求不会自行扩张扫描或写入范围，也不再把自动模式误述为项目级硬沙箱。
- 文件工具、编辑建议、删除结果和问卷恢复完成稳定性收口；文件侧栏在窄宽下不再裁切关键控件，Session CAS 冲突后的问卷状态可按权威数据恢复，重复或延迟结果不会覆盖较新的会话状态。
- 会话归属与文件树浏览解耦，并支持通过项目菜单或整行拖拽显式迁移会话。目标项目的主文件夹与共享次文件夹由服务端权威预览，新增访问范围先确认，再以状态令牌、revision 和原子写入提交。
- Code Web 完成视觉系统最终收口：执行轨迹、行内代码、文件区、Theme picker、Toast、新建文件夹、压缩确认与 Key 同步弹层使用更一致的字号、间距、图标、焦点和响应式尺度，深浅主题及桌面 / 窄屏保持统一。

## Skills 与本地运行环境

- Bundled Skill 在启动时按目录补齐新版本新增项，不覆盖或合并已有 bundled、local 或 custom 内容；用户删除 bundled Skill 后会持久记录删除意图，后续启动不会将其静默恢复。
- `runtimeResources` 只暴露清单中经过普通文件、reparse、大小和 SHA-256 校验的精确资源。已知旧版 bundled 安装可只读使用当前兼容资源，自定义同名 Skill 必须提供自己的清单；缺失、篡改、冲突或越界状态均稳定拒绝。
- XLSX 重算默认阻断外部链接、连接、查询及网络 / UNC 等外部引用，在隔离副本验证成功后才原子替换原文件；PPTX 校验拒绝宏，渲染使用独立 LibreOffice profile、有限超时和进程树清理。
- 同一 `DATA_DIR` 现在由单一 Code 实例持有系统级 owner lock；正式更新器只等待触发更新的精确进程，并在取得同一数据目录锁后才写入或启动替代版本，不再按名称枚举或强杀其他 Code 进程。

## 会话、项目与文件体验

- 会话迁移不会改变来源项目或目标项目的既有定义；需要补入目标项目的来源 root 时，只展示并确认新增访问范围。取消、冲突、忙碌、等待、归档和不安全根路径均不会产生部分写入，当前运行中的 AgentRun 工作区保持冻结。
- 项目编辑新增状态 CAS：主文件夹切换遇到陈旧页面时会加载最新权威状态并要求重新确认，避免覆盖其他客户端刚完成的名称或 root 修改；旧项目数据无需批量迁移。
- 拖拽迁移复用同一服务端预览与原子提交管线，提供跟随预览、完整项目块落点、边缘自动滚动、主题高亮、同项目 no-op，以及在成功、失败、取消和失焦后的完整状态清理。
- 文件工具组按执行顺序稳定投影终态；删除文件不再生成无内容编辑建议卡片。编辑建议与工具轨迹的间距、字号和信息层级更加紧凑，同时保留只读 Diff、授权弹窗和最终状态的原有职责边界。

## 安全与兼容边界

- 自动模式的提示是范围引导和风险披露，不是对任意 shell 子进程的项目路径隔离；危险命令、系统安装、破坏性 Git、授权状态、工具参数校验和既有 permission 边界保持不变。
- 新增的 Skill 资源、项目状态令牌和迁移计划不会扩大会话、AgentRun、模型 Route、工具或持久化权限；旧 Session、旧项目及无需新增 root 的旧迁移调用继续兼容，失败路径均以无静默覆盖和可恢复为原则。
- 本版本继续使用服务端权威的数据目录、Session revision 和原子写入边界；界面收口不改变输入、发送、附件、模型、Key、压缩、通知或系统权限的业务语义。
