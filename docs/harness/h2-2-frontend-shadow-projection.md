# Harness H2-2 前端只读影子投影

完成时间：2026-08-03 01:40（Asia/Shanghai）

阶段性质：在现有前端投影旁接入可关闭的只读观察器，不接管 UI、旧状态或持久化

## 1. 阶段目标

H2-2 将 H2-1 的纯 reducer 与规范 View Model 接入真实 AgentRun 事件和快照边界，同时保留现有消息投影、工具组、状态栏、问卷和授权逻辑作为唯一用户可见实现。

本阶段完成以下能力：

1. 前台任务、排队/刷新恢复任务和后台 AgentRun 均可同步执行影子计算；
2. 旧投影通过独立、只读且不解析 DOM 文案的适配器产生比较事实；
3. 七类 H2-1 字段在同一显式计时参考点比较；
4. 诊断只保存代码、字段、游标、状态与计数，且仅存在内存中；
5. 开发实例默认开启、正式实例默认关闭，关闭后不执行 reducer 或比较；
6. 影子观察失败时保持 fail-open，不阻断旧投影、游标提交、模型或工具执行。

## 2. 开关与实例默认值

服务端环境变量为 `CODE_AGENT_PROJECTION_SHADOW`，解析规则与其他 Harness 灰度开关一致：

| 场景 | 行为 |
| --- | --- |
| 开发实例 `INSTANCE_MODE=dev` | 默认开启 |
| 正式实例 `INSTANCE_MODE=release` | 默认关闭 |
| `1 / true / yes / on` | 显式开启 |
| `0 / false / no / off` | 显式关闭 |
| 空值或无法识别的值 | 回到实例默认值 |

`/api/browser-heartbeat` 只增加布尔能力字段 `agentProjectionShadow`。前端启动时保持关闭，收到心跳明确为 `true` 后才创建观察器；旧服务未返回该字段时仍保持关闭。

## 3. 接入边界与时序

### 3.1 前台、排队与刷新恢复

`projectAgentEvent()` 在旧投影开始前先把规范事件交给新 reducer；只有旧投影成功后，独立旧适配器才记录同一事件并进行事件级比较。若旧投影抛错，耐久游标仍按原规则不推进；相同事件重放时，新 reducer 幂等，旧适配器可以在旧投影成功后补齐。

`watchAgentRun()` 的 `onSnapshot` 在本轮事件全部成功投影后执行快照级比较。排队消息和刷新恢复继续复用同一个前台 AgentRun 循环，因此不增加新的执行分支。

### 3.2 后台 AgentRun

后台任务原本不生成父会话中的逐事件 UI 投影，因此事件级旧适配器只记录结构化时间线与本地观察到的轮次/工具 ID；快照级状态、待处理类型、轮次、工具数量和计时继续使用后台任务原有的服务端快照与耗时事实。观察器不改变后台调度、授权、超时、结果合并或会话隔离。

### 3.3 观察结束

终态快照或任务清理时，将单次 Run 汇总为内存级脱敏摘要。每个 Run 最多保留 64 条诊断样本，代码级计数继续累计；当前页面最多保留最近 32 个前台/后台 Run 摘要。摘要不包含 Run ID、会话 ID、模型文本、思考文本、工具参数、工具结果、命令输出、文件内容、diff、错误原文、Key、Authorization 或 Cookie。

## 4. 比较契约

快照边界比较 H2-1 冻结的全部七类字段：

- `status`
- `terminalStatus`
- `modelRoundCount`
- `toolCount`
- `pendingKind`
- `elapsedMs`
- `timeline`

事件边界始终比较 `timeline`；前台 `model_started` 额外比较模型轮数，前台工具开始/完成事件额外比较唯一工具数。后台完整字段在快照边界比较，避免把“后台原本没有逐事件消息投影”误判为差异。

旧时间线适配器拥有独立的事件类别、状态和引用字段映射，不复用新 reducer 的映射函数；因此任一侧映射错误都能形成真实差异。两侧计时共用同一个调用方参考时间，避免两次墙钟读取制造毫秒级误报。

## 5. 数据、兼容与回退

- 新 reducer、旧适配器和诊断均不访问 DOM、网络、存储或系统当前时间；墙钟只由 `app.js` 在观察边界读取一次并显式传入。
- 不新增或改写 AgentRun 持久字段、会话 JSONL、工具协议、模型请求、消息对象、UI 状态或 API 业务响应。
- 默认 bundle 与经典回退页都装载观察模块，但正式实例默认关闭；旧页面或旧服务缺少心跳字段时自动保持关闭。
- 最快回退方式是将 `CODE_AGENT_PROJECTION_SHADOW=0` 并重启对应实例；无需迁移或清理任何历史数据。代码级回退可单独撤销 H2-2，不要求回退 H2-1 纯契约。
