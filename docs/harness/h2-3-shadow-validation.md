# Harness H2-3：真实影子投影验证

当前状态：进行中

## 1. 验证目标

在 Code Dev 的真实 AgentRun 中观察规范 reducer 与现有前端投影是否一致，覆盖普通多工具、授权/问卷、连续刷新恢复、队列、后台任务和失败/取消。H2-3 只有在关键轨迹重复观察为零差异后才能收口；自动测试不能替代真实任务证据。

## 2. 只读摘要入口

开发实例默认启用 `CODE_AGENT_PROJECTION_SHADOW`。任务进入终态后，可在浏览器开发者工具 Console 中执行：

```javascript
window.Code.agent.projectionShadowDiagnostics.snapshot()
```

复制格式化结果：

```javascript
copy(JSON.stringify(window.Code.agent.projectionShadowDiagnostics.snapshot(), null, 2))
```

返回报告只存在于当前页面内存，最多包含最近 32 条已经归档的前台/后台 Run 摘要。刷新页面会清空此前页面中的摘要，不会写入会话 JSONL、AgentRun、浏览器存储或服务端。

## 3. 摘要边界

报告只允许以下字段：

- 开关、版本、数量和前台/后台计数；
- 观察到的事件、快照、比较、差异、观察器错误和丢弃诊断数量；
- 白名单诊断代码、比较字段、事件游标和八类规范状态。

导出边界会再次构造白名单副本。即使页面内存对象被意外加入 Run ID、会话 ID、模型正文、工具参数/结果、命令输出、文件内容、diff、错误原文、Key 或请求头，这些字段也不会出现在报告中。关闭影子开关时，入口只返回 `enabled: false` 的空报告。

## 4. 第一批真实测试顺序

每次只执行一个场景并在任务完整结束后提取报告，避免多个问题混在同一摘要中：

1. 普通前台多工具任务（已通过）；
2. `request_user_input` 问卷等待、提交和继续（已通过）；
3. 文件编辑或命令授权接受（命令路径已通过）；
4. 文件编辑或命令授权拒绝（命令路径已通过）；
5. 模型运行中刷新一次并恢复（已通过）；
6. 工具运行中连续刷新并恢复（已通过）；
7. 排队消息；
8. `/parallel` 后台任务；
9. 模型阶段取消；
10. 命令阶段取消或失败。

每个场景记录：页面行为是否正常、报告中的新增 `summaryCount`、`runKind`、`status`、`mismatches`、`observerErrors`、`diagnosticCounts` 和 `diagnostics`。任何差异先保存脱敏字段与复现步骤，再决定修复哪一侧，不根据 UI 文字猜测领域状态。

## 5. 本阶段已完成的准备

- 新增只读 `projectionShadowDiagnostics.snapshot()` 页面内存入口；
- 影子开关关闭时不返回历史摘要；
- 导出结果有独立 32 条上限和严格字段/枚举白名单；
- 返回全新副本，调用方修改报告不会污染页面中的原始摘要；
- 自动测试覆盖有界、关闭、聚合、复制和伪造敏感字段过滤；
- 默认 bundle 与经典回退页均能通过现有构建门禁。
