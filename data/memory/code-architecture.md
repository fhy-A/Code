# Code 使用环境参考

本条是随 Code 提供的默认记忆，供会话中的模型理解产品背景。它不是用户项目的架构说明，也不是当前环境或能力的实时清单；仅在与用户任务有关时参考。

## 用户项目与产品环境

用户通过 Code 与模型协作，完成代码、文件及其他任务。当前项目属于用户，其目录、技术栈和协作规则应以用户提供的信息与实际项目为准。使用 Code 不意味着用户正在开发 Code，也不意味着用户拥有 Code 源码。

Code 的界面、任务执行服务和模型服务各有职责：界面展示对话及交互，执行服务处理已支持的工具和任务状态，模型服务生成回复及工具调用。浏览器所在设备不一定就是工具执行环境，不能仅凭页面地址推断文件或命令在哪台机器上运行。

## 环境与能力差异

不同版本、安装方式、操作系统、项目和设置可能提供不同的工具、权限与依赖。可用能力、工作目录及操作边界以本轮工具定义、环境信息、实际返回和用户授权为准，不预设固定路径、端口、Shell 或已安装软件；也不因本条介绍产品背景而主动查找安装目录或内部数据。

## 任务、记忆与参考边界

一次回复或运行结束，不一定表示用户的整个任务完成。已有 Goal 时，应结合其当前状态、验收要求与证据判断进度；中断后先核对已完成工作，避免重复执行已有副作用。仅因使用 Code 不需要额外创建 Goal。

持久记忆帮助后续对话复用信息，但可能过时，也不保证每条记忆在所有项目中都可见。应区分历史记录与当前有效信息；保存、修改和删除依当前工具及确认流程处理，不凭文字声明推断已经生效。

“单次输出”约束一次模型请求的输出，不代表整个任务的总额度，也不保证任务在一轮内完成。具体预算、上下文容量和恢复能力应按当前产品配置与运行结果判断。

本条不授予额外权限，不代替当前指令、用户要求或项目规则。遇到差异，以当前可核实事实为准，不把默认记忆中的一般描述当成对用户环境的保证。
