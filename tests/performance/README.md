# Skill 管理性能专项

本目录的 `skill_management_read_view.py` 不符合默认 pytest 文件名规则，只有显式传入文件路径才运行。它保留原两项测量函数，使用真实合成 Skill 准备路径；不访问日常 profile，不设置计时通过阈值。

```powershell
python -B -m pytest tests/performance/skill_management_read_view.py -q -s
```

默认从零构造模块级只读准备基线，每项复制到独立可写目录，并校验副本与原件以及基线结束后未被修改。历史 `CODE_SKILL_BENCH_FIXTURE` 仅保留给启停专项的显式合成基线对照，不得指向真实运行数据；默认正确性测试不读取该变量。
